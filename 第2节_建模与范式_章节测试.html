一、选择题（每题 2 分，共 40 分）

1. ER 图中，弱实体用什么图形表示？

✓ 正确！ 弱实体用双线矩形表示，其标识关系用双线菱形表示。

2. 派生属性在 ER 图中用什么图形表示？

✓ 正确！ 派生属性用虚线椭圆表示（如年龄可由出生日期派生）。

3. ER 图中 M:N 关系转化为关系模式时应该？

✓ 正确！ M:N 关系必须单独建表，含双方主键为外键，主键为两外键组合。

4. 弱实体的主键由什么组成？

✓ 正确！ 弱实体没有独立主键，主键 = 拥有者主键 + 部分键（区分符）。

5. Armstrong 公理系统中，以下哪个不是基本公理？

✓ 正确！ 合并律是推论而非基本公理。三个基本公理：自反律、增广律、传递律。

6. 给定 R(A,B,C,D)，FD={A→B, B→C}，则 A⁺ = ？

✓ 正确！ A→B 得 AB，B→C 得 ABC。D 不在闭包中，因为无依赖能导出 D。

7. 2NF 消除了什么问题？

✓ 正确！ 2NF 要求非主属性完全函数依赖于候选键，消除部分依赖。

8. 关于 BCNF，以下说法正确的是？

✓ 正确！ BCNF 的核心条件：所有非平凡 FD 的决定因素都是超键。BCNF 不一定保持依赖。

9. 多值属性在转化为关系模式时应该？

✓ 正确！ 多值属性必须新建表，主键 = 全部列（实体主键 + 属性值）。

10. BCNF 分解算法保证什么？

✓ 正确！ BCNF 分解保证无损连接但不一定保持函数依赖。3NF 分解两者都保证。

11. 函数依赖 X→Y 是平凡依赖，当且仅当？

✓ 正确！ Y ⊆ X 时是平凡依赖，如 {A,B}→{A}，恒成立。

12. 3NF 与 BCNF 的主要区别是什么？

✓ 正确！ BCNF 不允许任何非平凡 FD 的决定因素不是超键（包括主属性间的依赖），3NF 对主属性间的依赖放宽了条件。

13. 属性闭包 X⁺ 包含所有属性说明什么？

✓ 正确！ X⁺ 包含所有属性 ⇒ X 是超键。若 X 的任何真子集的闭包都不包含所有属性，则 X 是候选键。

14. 特化 (Specialization) 是指什么过程？

✓ 正确！ 特化是自顶向下（一般→特殊），泛化是自底向上（特殊→一般）。

15. 4NF 消除了什么问题？

✓ 正确！ 4NF 要求所有非平凡 MVD 的决定因素都是超键，消除多值依赖带来的冗余。

16. 复合属性在转化为关系模式时应如何处理？

✓ 正确！ 复合属性（如地址=省+市+区）展开为多个简单列，每个子属性成为独立列。

17. 给定 FD={A→B, BC→D}，以下哪个依赖能从 Armstrong 公理推导？

✓ 正确！ 增广律：A→B ⇒ AC→BC；传递律：AC→BC 且 BC→D ⇒ AC→D。

18. 最小覆盖 (Canonical Cover) 中，每个 FD 的右边应是什么形式？

✓ 正确！ 最小覆盖中每个 FD 的右边必须是单个属性（如 A→B, A→C 而非 A→BC）。

19. 1:1 关系在转化为关系模式时，外键放在哪里？

✓ 正确！ 1:1 关系只需在任一方加外键即可。也可以合并为一张表。

20. 关于 ER 图到关系模式的转换，以下说法错误的是？

✓ 正确！ M:N 关系必须单独建关系表，不能在任一方加外键。这是最常见的错误。

二、判断题（每题 1 分，共 10 分）

21. 弱实体可以独立存在，有自己的主键。

✗ 错误！ 弱实体依赖强实体存在，没有独立主键，主键=拥有者主键+部分键。

22. 自反律是 Armstrong 公理之一：若 Y ⊆ X，则 X→Y。

✓ 正确！ 自反律、增广律、传递律是 Armstrong 三大基本公理。

23. 1NF 要求关系中所有属性都具有原子性（不可再分）。

✓ 正确！ 1NF 是最基本的要求：每个属性值都是原子的，没有嵌套表或多值列。

24. BCNF 分解一定能保持所有函数依赖。

✗ 错误！ BCNF 分解保证无损连接，但不一定保持依赖。3NF 分解两者都保证。

25. 传递依赖是违反 3NF 的根本原因。

✓ 正确！ 3NF 要求非主属性不传递依赖于候选键，消除传递依赖。

26. 每个函数依赖 (FD) 也是一个多值依赖 (MVD)。

✓ 正确！ 每个 FD 都是 MVD 的特例。但反过来 MVD 不一定是 FD。

27. 属性闭包 X⁺ 的计算结果依赖于 FD 的处理顺序。

✗ 错误！ 闭包计算结果唯一，与处理顺序无关。中间结果可能不同但最终一致。

28. ER 图中，关系 (Relationship) 用菱形表示。

✓ 正确！ 实体→矩形，属性→椭圆，关系→菱形，是 ER 图的基本符号规则。

29. 泛化 (Generalization) 是自顶向下的过程。

✗ 错误！ 泛化是自底向上（子类→父类），特化是自顶向下（父类→子类）。

30. 3NF 合成算法保证无损连接和保持依赖。

✓ 正确！ 3NF 合成算法同时保证无损连接和保持函数依赖，这是它相比 BCNF 分解的优势。

三、填空题（每题 2 分，共 20 分）

31. ER 图中， 属性用双线椭圆表示。

答案：多值 — 如电话号码（一个实体可以有多个值）。

32. 弱实体的主键 = 拥有者主键 + 。

答案：部分键 / 区分符 — 用于区分同一拥有者下的不同弱实体。

33. Armstrong 三大公理：自反律、、传递律。

答案：增广律 — 若 X→Y 则 XZ→YZ。

34. 依赖是非主属性对候选键的部分依赖，违反 2NF。

答案：部分 — 部分函数依赖是违反 2NF 的根源。

35. BCNF 要求所有非平凡 FD 的 都是超键。

答案：决定因素 / 左边 / 左部 — 即每个 FD X→Y 的 X 必须是超键。

36. 4NF 消除了由非平凡 引起的冗余。

答案：多值依赖 / MVD — 如课程→→教材（一门课可用多本教材）。

37. 与 F 等价的、最简函数依赖集称为 。

答案：最小覆盖 / Canonical Cover / Fc — 每个FD右边单属性，无冗余。

38. ER 图中 关系表示弱实体与其拥有者之间的关系。

答案：标识 / Identifying — 用双线菱形表示。

39. 自底向上从子类抽象出父类的过程称为 。

答案：泛化 / Generalization — 与特化（自顶向下）方向相反。

40. BCNF 分解算法保证 连接，但不一定保持函数依赖。

答案：无损 / Lossless — 可通过自然连接恢复原始关系。

四、简答题（每题 5 分，共 20 分）

41. 简述 ER 图中 M:N 关系、1:N 关系、1:1 关系分别如何转化为关系模式？

参考答案：1:1 关系：在任一方添加外键指向对方主键。1:N 关系：在 N 方添加外键指向 1 方主键。M:N 关系：必须新建关系表，包含双方主键作为外键，关系表的主键为两个外键的组合。此外关系自身如有属性也放在关系表中。

42. 解释 2NF、3NF、BCNF 各自消除了什么问题，并说明它们之间的递进关系。

参考答案：2NF 消除部分依赖（非主属性部分依赖于候选键），3NF 消除传递依赖（非主属性传递依赖于候选键），BCNF 消除主属性间的依赖（所有非平凡FD的决定因素都是超键）。递进关系：BCNF ⊂ 3NF ⊂ 2NF ⊂ 1NF，BCNF 最严格。3NF 保证无损连接+保持依赖；BCNF 保证无损连接但不一定保持依赖。

43. 简述属性闭包 X⁺ 的计算算法及其两个主要用途。

参考答案：算法：result=X，反复遍历FD集：若某FD的左部⊆result，将右部加入result，直到不变。用途1：判断超键——若X⁺包含所有属性，则X是超键。用途2：判断依赖蕴含——若Y⊆X⁺，则X→Y被F蕴含。

44. 什么是最小覆盖 (Canonical Cover)？简述计算最小覆盖的步骤。

参考答案：最小覆盖Fc是与F等价的最简函数依赖集，每个FD右边只有单个属性且无冗余属性/依赖。步骤：1.将所有FD右边分解为单属性（用分解律）。2.检查每个FD左边有无冗余属性（逐一移除，检查是否等价）。3.检查每个FD本身是否冗余（逐一移除，检查是否等价）。

五、综合题（10 分）

45. 给定关系模式 R(A, B, C, D, E)，函数依赖集 F = {A→BC, CD→E, B→D, E→A}。
(1) 求 R 的所有候选键
(2) 判断 R 属于第几范式，说明理由
(3) 若不属于 BCNF，请分解到 BCNF

参考答案：
(1) 计算各属性闭包：A⁺={A,B,C,D,E}→A是超键；B⁺={B,D}≠全部；E⁺={E,A,B,C,D}→E是超键；CD⁺={C,D,E,A,B}→CD是超键。候选键：A, E, CD（三个）。
(2) 检查 BCNF：FD B→D，B不是超键（B⁺={B,D}），违反BCNF。所以R最高为3NF（检查：无非主属性的部分/传递依赖问题，主属性间的依赖违反BCNF但不违反3NF）。
(3) 用 BCNF 分解：选 B→D 分解，R1(B,D)，R2(A,B,C,E)。R1 中 B→D 且 B 是 R1 的超键→BCNF。R2 中 FD 有 A→BC, E→A。A⁺={A,B,C}⊂R2（缺E），A不是超键，用 A→BC 分解：R2a(A,B,C)，R2b(A,E)。R2a 中 A→BC 且 A 是超键→BCNF。R2b 中 A→E 且 A 是超键→BCNF。最终分解：{BD, ABC, AE}。
